# Day 97/184

## Graph Refresher

### Types

- Directed vs Undirected
- Weighted vs Unweighted
- Cyclic vs Acyclic
- Connected vs Disconnected

### Representations

- Adjacency List: O(V+E) space, good for sparse graphs
- Adjacency Matrix: O(V²) space, fast edge lookup

### Traversals

- DFS: stack/recursion, go deep first
- BFS: queue, go wide first

### Key Insight

Trees = graphs with no cycles and one root.
All tree traversal knowledge transfers here.
