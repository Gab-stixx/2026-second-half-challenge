## System Analysis & Design — Exam Prep

### Topics Covered

#### Definitions
- System: collection of components working together toward a goal
- Analysis: understanding WHAT the system should do
- Design: deciding HOW the system will do it

#### Methodologies
- Waterfall: sequential, phase by phase
- Agile: iterative, flexible, continuous delivery
- Spiral: risk-driven, repeated cycles

#### Tools
- DFDs (Data Flow Diagrams)
- ERDs (Entity Relationship Diagrams)
- Use Case Diagrams
- Flowcharts

#### Techniques
- Interviews, surveys, observation (requirements gathering)
- Feasibility studies (technical, economic, operational)
- Prototyping

### Reflection
Coding is only one part of software engineering.
Understanding how systems are planned and analyzed is equally important.
