## LeetCode 75: BFS Refresher

### What I Reviewed

Before starting the next problems, I refreshed my understanding of Breadth-First Search (BFS).

BFS explores a tree level by level, using a queue to keep track of the nodes that need to be visited.

### Basic Idea

```text
1. Add the starting node to the queue
2. Take a node from the front
3. Process the node
4. Add its children to the queue
5. Repeat until the queue is empty
```

### Key Takeaway

BFS is especially useful when we need to process or find something level by level in a tree.
