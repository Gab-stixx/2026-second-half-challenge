## Stack, Queue & Linked List Recap

### Stack (LIFO — Last In, First Out)
- Push and pop from same end
- Best for: matching problems, undo operations, expression evaluation

### Queue (FIFO — First In, First Out)
- Add from back, remove from front
- Best for: BFS, scheduling, order processing

### Linked List
- Nodes connected by pointers
- No fixed size, dynamic memory
- Best for: insertions/deletions at any position

### Key Insight
Knowing the theory is one thing.
Knowing WHEN to use which is another.
