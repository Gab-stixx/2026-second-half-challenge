## What I Refreshed

A heap is a tree-based data structure that follows a specific ordering rule.

A min-heap keeps the smallest element at the top, while a max-heap keeps the largest element at the top.

A priority queue is an abstract data type that allows elements to be processed according to their priority rather than simply the order in which they were inserted.

## Common Operations

For a typical binary heap:

| Operation                  | Time Complexity |
| -------------------------- | --------------- |
| Access minimum or maximum  | O(1)            |
| Insert an element          | O(log n)        |
| Remove the top element     | O(log n)        |
| Build a heap from an array | O(n)            |

## Key Learning

Heaps and priority queues are useful when a problem repeatedly requires the smallest or largest element, or when items need to be processed according to priority.
