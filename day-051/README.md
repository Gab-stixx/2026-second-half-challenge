## Hash Maps & Hash Sets

### Hash Map
- Key-value pairs
- O(1) average lookup, insert, delete
- Keys must be unique
- Example: { "name": "Gabriel", "age": 21 }

### Hash Set
- Stores unique values only
- O(1) average lookup, insert, delete
- No duplicates allowed
- Example: { "apple", "banana", "mango" }

### Key Differences
- Map: stores key + value
- Set: stores key only

### When to Use
- HashMap: frequency count, caching, grouping
- HashSet: duplicate detection, membership check
