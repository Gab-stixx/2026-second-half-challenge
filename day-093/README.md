### Overview

To help solidify my React knowledge, I built a small Nigeria-themed quiz while continuing to learn and practice React.

The goal was to learn by building instead of only going through tutorials.

### What I Learnt

#### Redux State Management

* The store holds the application state.
* Actions such as `setUser` and `logoutUser` update the state.
* `useSelector` allows components to read from the Redux store.
* `useDispatch` allows components to dispatch actions.
* This allows different parts of the application, such as the sidebar and navbar, to stay updated with the same state.

#### Tailwind CSS

I also practiced styling a React application using Tailwind CSS utility classes.
