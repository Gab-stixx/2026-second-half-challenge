## Training: Introduction to Bash & Shell Scripting

### Learned Today

#### Command Line Basics
- **pwd:** Print working directory
- **cd:** Change directory
- **ls:** List files/directories
- **mkdir:** Create directory
- **touch:** Create empty file

#### File Operations
- **cp:** Copy files
- **mv:** Move/rename files
- **rm:** Remove files
- **cat:** Display file contents
- **grep:** Search text patterns

#### Text Processing
- **sed:** Stream editor (find/replace)
- **awk:** Text processing language
- **cut:** Extract columns
- **sort:** Sort lines
- **uniq:** Remove duplicates

#### Piping & Redirection
- **|** (pipe): Pass output to next command
- **>** (redirect): Send output to file
- **>>** (append): Append output to file
- **<** (input): Read from file

#### Shell Scripting
- Writing .sh files
- Variables and loops
- Conditional statements
- Automation concepts

### Why Bash Matters
- System automation
- DevOps & deployment
- File management at scale
- Understanding Unix/Linux
- Backend infrastructure

### First Impressions
- Different from high-level languages
- Direct system interaction
- Powerful for automation
- Steep learning curve initially

- Automate repetitive tasks
